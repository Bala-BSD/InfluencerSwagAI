1. Executive Summary: Self-Contained AI Content Studio
A complete content creation IDE powered entirely by Large Language Models, eliminating external API dependencies while maintaining full functionality through advanced prompt engineering and structured data processing.

2. Core Architecture Principle
"Everything as Prompt Engineering" - All modules transform user inputs into structured prompts that guide LLMs to perform specialized functions without external integrations.
